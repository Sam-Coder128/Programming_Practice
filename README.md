**#C Programming – Basic to Advance**
Author: Samruddh Shivkumar Birajdar

*📘 Overview*
This repository contains a structured journey through C programming, starting from fundamentals and progressing to advanced system‑level concepts. Each file demonstrates a specific concept with clean headers, modular design, and industrial documentation.

*📂 Topics Covered*
Data types → basic variable declarations, ranges, and usage.
Control structures → if‑else, loops, switch.
Strings → creation, traversal, access, comparison.
Pointers → pointer arithmetic, call by address, string length.
Structs → direct/indirect access, arrays of structs, alignment, packing.
Static concepts → static variables, memory behavior.
File handling → open, write, read, close, unlink.
Dynamic memory → malloc, calloc, free.
Modular projects → multi‑file compilation with headers and helpers.
Arithmetic operations → addition, subtraction, multiplication, division, modulus.
Struct alignment & padding → default vs packed struct layouts.
System calls → low‑level POSIX operations (open, write, unlink).

*📂 Folder Highlights*
Maths_project/ → arithmetic operations in modular design.
